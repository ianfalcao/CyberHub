# CyberHub

O **CyberHub** é um projeto acadêmico desenvolvido como parte das disciplinas de Desenvolvimento Front-End para Web, com o objetivo de apresentar informações sobre o universo da Segurança da Informação e Cibersegurança.

## Sobre o projeto

O portal reúne conteúdos introdutórios sobre segurança digital, incluindo:

- **Notícias:** informações e novidades relacionadas à cibersegurança.
- **Vulnerabilidades:** apresentação de vulnerabilidades conhecidas e seus respectivos CVEs.
- **Ferramentas:** informações sobre ferramentas utilizadas na área de segurança da informação.
- **Login e Cadastro:** páginas demonstrativas para interação com formulários.

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript

## Funcionalidades

- Navegação entre as páginas do portal.
- Formulários de cadastro e login.
- Validação de campos obrigatórios com JavaScript.
- Verificação de confirmação de senha no cadastro.
- Redirecionamento entre páginas.

**Observação:** O sistema de login e cadastro é demonstrativo. Não possui autenticação real, banco de dados integrado ou armazenamento de usuários.

## Objetivo acadêmico

O projeto tem como finalidade aplicar os conhecimentos iniciais de desenvolvimento web, estruturação de páginas, estilização com CSS, manipulação básica do DOM com JavaScript e conceitos de modelagem de banco de dados.
